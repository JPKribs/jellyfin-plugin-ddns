# DDNS.fm

In step 2, **Address**, of the **Configuration** tab, set **Provider** to **DDNS.fm**, then fill in:

- **Domain**: your DDNS.fm domain.
- **Key**: the update key from your DDNS.fm dashboard.
- **Server override**: leave blank to use DDNS.fm's own server.

_Ported from ddclient's `nic_ddnsfm_update`._
