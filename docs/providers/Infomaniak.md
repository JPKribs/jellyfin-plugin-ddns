# Infomaniak

In step 2, **Address**, of the **Configuration** tab, set **Provider** to **Infomaniak**, then fill in:

- **Hostname**: the record.
- **Username**: your Infomaniak dynamic DNS username.
- **Password**: your Infomaniak dynamic DNS password. Create dynamic DNS credentials for the domain in the Infomaniak Manager.
- **Server override**: leave blank to use Infomaniak's own server.

_Ported from ddclient's `nic_infomaniak_update`._
