# 1984 Hosting

In step 2, **Address**, of the **Configuration** tab, set **Provider** to **1984 Hosting**, then fill in:

- **Domain**: the domain.
- **API key**: your 1984 Hosting API key, which is the FreeDNS API key in your 1984 account.
- **Server override**: leave blank to use 1984 Hosting's own server.

_Ported from ddclient's `nic_1984_update`._
