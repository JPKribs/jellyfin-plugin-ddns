# DSLReports

Set the record's **Provider** to **DSLReports**, then fill these fields.

- **Hostname**: your DSLReports host id.
- **Login**: your DSLReports username.
- **Password**: your DSLReports password.

This protocol carries a single IPv4 address, so the IPv6 (AAAA) toggle is hidden for it.

_Ported from ddclient's `nic_dslreports1_update`._
